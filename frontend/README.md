# Expense Tracker (frontend)

React + Vite single-page app for the Expense Tracker project.

See the project-wide **[README](../README.md)** for architecture, setup and the money rules.

```powershell
npm install
Copy-Item .env.example .env
npm run dev        # http://localhost:5173
```

The backend must be running at the origin in `VITE_API_BASE_URL` (default
`http://localhost:8000`).
